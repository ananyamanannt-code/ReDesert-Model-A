# Re:Desert — Model B

## Experimental Satellite Vegetation Persistence Prediction

Model B uses satellite-derived environmental features and machine learning to investigate vegetation persistence in the UAE desert.

**Objective:** Identify patterns associated with vegetation persistence to support future desert restoration research.

**Inputs:** Satellite vegetation indices, environmental features, and historical observations.

**Model:** Random Forest classifier.

**Limitations:** This is an experimental model. It does not establish native tree survival, irrigation requirements, or planting-site suitability without further field validation.

**Project:** Re:Desert — Satellite Intelligence and AI for Self-Sustaining Desert Restoration.
